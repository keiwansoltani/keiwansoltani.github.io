# Keiwan Soltani — Professional Portfolio

A responsive static portfolio featuring research publications, UAV projects, AI applications, and professional experience.

## Publish with GitHub Pages

1. Add these files to the root of your portfolio repository, keeping the `assets` folder intact.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select your default branch (usually `main`), choose **/(root)**, and click **Save**.
5. GitHub will display the website address when deployment completes.

Future commits to the selected branch automatically publish updates. No build tools or package installation are required. The `.nojekyll` file ensures direct static-file publishing.

## Update your portfolio

| File | What to edit |
| --- | --- |
| `index.html` | Biography, projects, publications, experience, and contact links |
| `style.css` | Colors, typography, layout, and responsive styling |
| `script.js` | Mobile menu and publication filtering |
| `sources.html` | Research sources and attribution notes |
| `assets/Keiwan_Soltani_CV.pdf` | Replace with your updated CV using the same filename |
| `assets/drone.mp4` | Drone video |
| `assets/drone.jpg` and `assets/mini-drone.jpg` | Project photos |
| `assets/video-poster.jpg` | Video preview image |

For text changes, open the file on GitHub, choose the pencil icon, edit, and commit. For replacement media, use **Add file → Upload files** in the assets folder. Keep filenames unchanged unless you also update their references in `index.html`.

To preview locally, open `index.html` in a browser. All website links use relative paths, so the same files work for a personal site or a project repository site.
